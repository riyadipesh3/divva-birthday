# A little celebration for Divva

A birthday keepsake from Daniel, with an animated invitation, a letter, little wishes, balloons, and cake.

[Open the birthday website](https://riyadipesh3.github.io/divva-birthday/)

This repository contains the deployable website files. Personal birthday content is encrypted; the password and unencrypted letter are not stored here. The original editable content is kept separately.

GitHub Pages publishes the root of the `main` branch. No dependencies or build step are required for these deployment files. To publish an update, replace them with the freshly encrypted build and push.

Font licenses are included in `assets/`.
